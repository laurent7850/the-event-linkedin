# Réalisations

Répertoire dédié aux réalisations du projet The Event LinkedIn.

## Contenu

Ce dossier regroupe les réalisations concrètes liées au projet :
exemples de campagnes, cas d'usage, livrables et supports associés.

## Organisation

Créer un sous-dossier par réalisation, nommé `AAAA-MM-nom-de-la-realisation`,
contenant au minimum un `README.md` décrivant :

- le contexte et l'objectif
- les étapes / le déroulé
- les résultats obtenus
